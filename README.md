## Project Overview

This project aims to create a LEGO video game based on the classic **LEGO Racers** PC game, enhanced with elements from **LEGO Island 2**, and featuring all the iconic LEGO Space themes from the 1990s. The game will be developed as a modification/extension of the original LEGO Racers engine.

## Game Features

- **Expanded Vehicle Creator** — based on LEGO Racers' car creation system, with more parts and customization options from all Space themes.
- **Character Customization** — create your own astronaut minifigure with parts from every included theme.
- **Themed Tracks** — race on tracks inspired by each Space theme, with unique environments and obstacles.
- **Story Mode** — incorporates LEGO Island 2's adventure elements with a story spanning all Space factions.
- **Multiplayer Racing** — local and online multiplayer with support for custom vehicles.
- **Original Soundtrack** — music inspired by the classic LEGO Space themes with modern production.

## Guided Free-Build System

An innovative building system that combines the freedom of creative construction with the guidance of official LEGO instructions.

### 1. The "Reference" Panel (Left 20%)

An interactive viewer for the official instruction booklet — not a locked step-by-step guide.

- Flip through scanned instruction pages (Page 1 of 20, 2 of 20…)
- Just like having the physical book open on your desk
- Current page displayed clearly — no forcing, no locking parts
- Simple navigation controls

### 2. The "Smart" Part Palette

The palette doesn't restrict parts — it *suggests*.

- Special **"Suggested Parts"** / **"Next Parts"** mode
- Based on the current instruction page, relevant bricks are highlighted or subtly glow
- Visual indicators such as: *"This page uses: 4× 2×4 Red Brick, 1× 2×2 Slope, 2× 1×2 Blue Plate"*
- Helps players find what they need without restricting creativity

### 3. The Freedom

- **Veteran Builders** — work from memory, glancing at the manual only for complex sections
- **New Players** — follow instructions meticulously with the "suggested parts" highlight
- **Creative Players** — use instructions as inspiration, then modify designs with their own flair
- **Mix & Match** — combine parts from different sets since the palette isn't locked down

### Why This Approach Works

- **Respects player agency** — treats the player like an AFOL with a manual open next to their building plate.
- **Solves the "I can't find the piece!" problem** — the "suggested parts" highlight eliminates scanning a big pile of bricks.
- **Scalable implementation** — no complex step-by-step logic per set; just associate instruction pages with part IDs.
- **Fits the LEGO vibe** — provide tools and inspiration, then get out of the way.

### Technical Implementation

- Instruction manuals stored as high-quality PNG images with a navigation system
- JSON database mapping instruction pages → part IDs and quantities
- Visual highlighting system for the part palette
- Non-intrusive UI that doesn't interfere with creative building
- Compatible with all planned Space themes and sets

## Development Guide

1. **Engine Analysis** — reverse engineer the LEGO Racers engine; document file formats for models, textures, and tracks.
2. **Asset Pipeline** — build a workflow for converting LEGO set instructions into 3D models; develop tools to extract and create parts.
3. **3D Modeling** — model all LEGO parts from the collected sets, accurate to real pieces and optimized for performance.
4. **Track Design** — design race tracks inspired by each Space theme; concept art and blockouts before full implementation.
5. **Programming** — modify the LEGO Racers engine to support expanded creation tools and additional game modes.
6. **Testing** — extensive testing of vehicle physics, track design, and multiplayer stability.
