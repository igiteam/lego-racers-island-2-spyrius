
# lego-racers-island-2-spyrius
## LEGO Racers - LEGO Island 2 - Spyrius Remake
A total conversion mod that remakes the LEGO Racers and LEGO Island 2 experience through the lens of the classic 1990s LEGO Spyrius space theme — stealth, saucer craft, spy droids, and stolen technology.
